# In newsfeed_card.dart, I made the post image optional using the hasImage boolean. When a card is created, I can set hasImage to true to display the owl picture using Flutter’s Image widget. When it’s false, the image area is skipped, so text only posts still look clean. also registered the image in pubspec.yaml so Flutter can load it as an asset.
